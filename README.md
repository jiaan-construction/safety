# JIA AN Crane Operator Safety Acknowledgement

JIA AN Construction Pte. Ltd. 塔吊司机线上安全须知与确认系统 V1.0。

## 正式网站 / Live website

**https://jiaan-construction.github.io/safety/**

请把上面的网页链接发给司机，或将该链接制作成二维码供司机扫码。不要直接发送 `index.html` 文件；WhatsApp 和微信通常无法直接预览 HTML 附件。

## 系统用途

本网站用于让塔吊司机：

1. 阅读 JIA AN 公司级塔吊安全须知；
2. 逐节确认已经阅读并理解；
3. 填写姓名、联系电话及选填的 FIN / Work Permit；
4. 输入姓名作为电子签署确认；
5. 生成带确认编号、确认时间和阅读记录的回执；
6. 将回执发回公司存档。

这是 Safety Acknowledgement（安全须知确认），不是免责协议，也不能替代培训、能力评估、项目安全交底、起重计划或总包现场规定。

## 司机使用方法

1. 用手机打开正式网站。
2. 点击 **Begin reading the safety document / 开始阅读安全文件**。
3. 填写姓名和联系电话；FIN / Work Permit 为选填。
4. 阅读全部安全章节，滑到每一节底部并完成确认。
5. 勾选最终声明，并输入与姓名栏一致的姓名完成签署。
6. 点击确认后，网站会生成 **Crane Operator Safety Acknowledgement Receipt / 塔吊司机安全须知确认回执**。
7. 点击 **Send receipt / 发送回执**，在手机分享菜单中选择 WhatsApp，并把回执图片发给指定的 JIA AN 联系人或工作群。
8. 如手机不能直接分享，长按网页生成的回执图片保存，再从 WhatsApp 发送；也可使用页面内的邮件方式发至 `jiaanjason1360@gmail.com`。

司机只有在 WhatsApp 或邮件中完成最后一次发送，公司才会收到回执。

## 公司使用方法

1. 把正式网站链接或二维码发给需要确认的司机。
2. 明确指定唯一的 WhatsApp 接收联系人或工作群。
3. 收到回执后，核对姓名、联系电话、文件版本、确认编号、日期和时间。
4. 按公司内部规则保存回执，并记录尚未回传的人员。
5. 文件升版、司机重新入职或公司要求重新确认时，重新发送网站链接并取得新回执。

## 当前回传与数据方式（V1.0）

- 网站是纯静态 GitHub Pages 页面，目前没有后台数据库。
- 姓名、电话、FIN、阅读进度和签署资料只在司机当前手机浏览器中处理。
- 点击最终确认只会在手机本地生成回执，不会自动上传给 JIA AN。
- **Send receipt / 发送回执** 会调用手机的系统分享功能；司机仍须自行选择正确的 WhatsApp 联系人或邮件并发送。
- 公司目前不能在网站后台查看谁已完成、谁未完成，也不能自动搜索历史记录。
- 刷新或关闭页面后，未回传的填写进度不保证保留。

## 下一阶段升级方向

下一版本应优先把“工人主动分享回执”升级为“公司自动收到并可查询”：

1. **自动提交**：工人完成签署后，将记录安全提交到公司指定后台。
2. **提交结果页**：明确显示提交成功、失败或需要重试，避免把“本地生成回执”误认为“公司已经收到”。
3. **管理后台**：按司机、日期、文件版本和确认编号查询及导出记录。
4. **状态追踪**：显示已发送、已收到、待确认、已失效和需要重签。
5. **审计记录**：保存服务端时间、文件版本、确认编号和确认文本快照；需要收集 IP、设备信息或其他个人资料前，先完成相应的隐私与合规评估。
6. **版本控制**：安全文件升版后，识别旧回执并通知相关司机重新确认。
7. **分层扩展**：在公司级确认之外，继续建设项目级 Site-specific Acknowledgement 和每日 Pre-Operation Safety Confirmation。
8. **保留人工副本**：即使自动提交成功，也允许司机下载或分享自己的回执副本。
